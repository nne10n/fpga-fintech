## 2. 系统目标与边界

### 2.1 目标

在 XC7Z020 级别 Zynq-7000 SoC 上实现工业振动/电流时序的边缘 1D-CNN 故障诊断节点：PL 完成采集前端、预处理与定点推理；PS 完成投票告警、上报与运维；形成可复用的「训练→量化→HLS IP→上板」示例工程模板。

### 2.2 场景与输入假设

- 信号：转速平稳或缓慢变化（不做阶次跟踪）。
- 训练数据：CWRU/公开集 + 少量实测；离线训练。
- 单节点独立运行，无多节点协同。
- 振动采集依赖外接 ADC（本板无 PCIe；XADC 不满足 ≥16-bit 同步采样需求）。

### 2.3 明确排除（Out of Scope）

- 变流器/电机控制闭环、无线组网协议栈、云端平台开发。
- DPU / FINN 路线实现（允许技术对照记录，非交付）。
- 封装与 EMC 认证。
- V1 内：**50% 重叠连续实时推理承诺**、双套权重热切换功能、瘦网络替换、多引擎并行。

## 3. 平台与工具链冻结

| 项目 | 冻结值 | 备注 |
| --- | --- | --- |
| 器件 | XC7Z020-1CLG400 级别（Z-7020） | LUT≈53,200；BRAM 140×36Kb≈630KB；DSP48E1×220 |
| 开发板 | ZYNQ7020 开发板（正点原子 / ALINX / 米联客等） | 选型以到货与 FMC/扩展座兼容 AD 子卡为准 |
| AD 子卡 | AD7606 级（≥16-bit，同步采样，≥100 kSPS） | SPI 或并行接口均可，前端模块以可配接口适配 |
| 工具链 | Vivado + Vitis HLS + Vitis/PetaLinux | 不引入 UltraScale+/Versal 专属 IP |
| 数据类型 | INT16 权重/激活 + INT32 累加 | INT8/2^k 免乘为后续压缩变体 |
| 主时钟目标 | PL 100–150 MHz | -1 速度等级；实现后 WNS≥0 且余量≥100 ps |

## 6. 基线网络与存储预算（写入契约）

### 6.1 基线网络（§4.2 锁定）

输入：2048×1（单通道特征；2 物理通道可分时/分引擎扩展，V1 默认按文档单流窗处理约定见架构书）。

| 层 | 配置 | 输出形状 | MAC | 参数(INT16) |
| --- | --- | --- | --- | --- |
| Conv1 | k=16, c=16, s=4 | 512×16 | 524k | 4.2 KB |
| Conv2 | k=8, c=32, s=4 | 127×32 | 1.04M | 16.6 KB |
| Pool | k=2, s=2 | 63×32 | ~0 | — |
| Conv3 | k=3, c=64, s=1 | 61×64 | 468k | 37.2 KB |
| GAP | — | 64 | 61 | — |
| FC | 64→10 | 10 | 640 | 1.28 KB |
| **合计** | | | **≈2.04M MAC** | **≈58 KB** |

BN 在训练侧折入卷积权重；运行时零 BN 开销。

### 6.2 BRAM 预算表（硬约束 ≤70%）

| 用途 | 预算 | 说明 |
| --- | --- | --- |
| 权重常驻 + 量化元数据 | ≤80 KB | **V1 单套**；双套属后续，不占 V1 预算 |
| 层间特征图双缓冲 | ≤260 KB | 按最大层 + 扩展预留 |
| 输入环形缓冲 + DMA 暂存 | ≤64 KB | 2ch ×4096×2B 量级 |
| 行缓存 / 移位窗口 | ≤32 KB | k=16 滑窗 |
| **合计** | **≤440 KB / 630 KB（70%）** | 超出则触发 tile/缓冲复用降档，须回签核 |

## 7. 验证与验收准则

### 7.1 分层验证链

1. **算法**：float32 → INT16 定点；逐层量化误差与精度差记录。
2. **bit-exact**：≥32 组向量（边界/全零/饱和）；HLS csim、C/RTL cosim、PyTorch 定点三者分数向量 0-bit 误差。
3. **综合与时序**：csyn 资源/II → Vivado 利用率与 WNS 满足 NFR-06/07。
4. **上板**：ILA/时间戳验证 NFR-01~03；72h 验证 NFR-09；功耗 NFR-08。
5. **场景**：留出实测集验证 NFR-04/05。

### 7.2 精度口径

- CWRU：12k DE、四档负载、10 类、窗长 2048；**按物理段/时间块切分**，禁止窗随机切分造成泄漏。
- 报告：accuracy + macro-F1 + 每类 P/R/F1 + 10 折均值±方差；SNR 曲线；固定种子。
- 现场留出集为主验收；公开集仅横向对比。

### 7.3 证据要求（FPGA skill）

任何签核通过必须附：日志 / 波形 / HLS 报告 / 实现报告 / 实测记录。无证据 = 不通过。结论仅允许：**PASS / FAIL / 有条件通过（附条件与责任人）**。
