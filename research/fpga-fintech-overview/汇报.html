01 / 生产

FPGA 已是生产默认件

行情处理、TCP 会话、交易前风控、L1 交换——不是概念验证，是机房里在跑的东西。

02 / 口径

纳秒竞赛是 I/O，不是全策略

公开纪录量的是触发字段进 FPGA 到 TCP 订单离 FPGA。完整策略路径不在这个数里。

03 / 机器学习

ML 是微秒级产品

GBT / LSTM 已可采购，公开金融推理多在 1–3 µs。还没走进 13.9 ns 那条热路径。厂商 kit 里有约 250 ns 的 inline GBT，仍是厂商数。

02

生产路径

关键路径四段，落在同一块 fabric。CPU 不在这条路上。

PHY PHY

线侧收包。10GbE 仍是公开超低延迟数字的主场。

PARSE 协议解析

A/B 仲裁、解码、归一化。行情进 FPGA，不进内核。

TRIGGER 触发模板订单

预装订单模板，硬件 trigger / update。复杂 alpha 仍在 CPU。

SEND TCP 发单

硬件 TCP 离 FPGA。STAC-T0 的钟，停在这一拍。

CPU OFF THE HOT PATH

07

密码学

HFT 热路径的公开材料几乎不谈 TLS / HSM。看得到的是硬件 TCP/UDP、FIX 会话、CRC。不宜写成主流用途。

04

为何是 FPGA

确定时延、线速并行、可改写。关键路径不走操作系统调度。

FPGA

PHY 到发单可落在同一块 fabric。生产主流：行情 + TCP + 风控 + 触发模板在 FPGA，复杂 alpha 在 CPU。

相对 CPU

CPU 仍跑策略、会话、审计。Feed、发单、风控如果走软件，抖动会上来。

相对 GPU

GPU 强在吞吐和训练。HFT 要的是 batch=1、抖动接近零。公开 STAC-ML 金融推理纪录目前在 FPGA 栈（Myrtle / Xelera）。

相对 ASIC

协议和监管会变，FPGA 可重配。eFPGA 嵌进 ASIC 不是主流加速卡形态。

不要把硅片 I/O 当成交易延迟。 AMD UL3524 / UL3422 的 GTF 收发器 <3 ns 是近端 loopback 的硅片 I/O，不含协议，不是交易延迟。

06

2024–2026 前沿

01

专用超低延迟硅片

UL3524 的 GTF + 硬化 MAC/PCS，支撑了 STAC STAC-T0 13.9 ns。

02

CXL SmartNIC

STAC STAC-N1（2024-05）已测。CXL 3.0 cache-coherent 进入热路径的公开生产案例仍少。

03

ML 产品化

STAC-ML 从 LSTM 扩到 El Popo GBT（2026-05）。大模型 / Transformer 没有纳秒级 tick-to-trade 的公开生产证据。

04

学术侧

LightTrader（HPCA 2023）；Liu et al.（IEEE ASAP 2024）订单簿 26–209 ns 论文；VLSI-TSA 2026 在 Alveo U50 上风控单笔约 518–530 ns 论文；O’Mahony Electronics 2024 期权定价相对 CPU 270–5400× 论文，这是定价 / 风险，不是发单。

05

LLM 写金融 Verilog

FinHardBench（arXiv:2608.00909，2026-08）：功能正确率 19–61% 论文。能综合，但算错很常见，不能当生产 RTL 主力。

07

尚未铺开 · 未来十二个月

困难、尚未铺开

  • 完整策略进 FPGA。
  • 纳秒级 ML：公开 inline GBT 约 250 ns 为厂商 kit；LSTM / NN 多在 1–3 µs。
  • 深订单簿对延迟：片上内存不够。
  • 公开超低延迟多数仍是 10G。
  • CXL 没有 T0 量级的热路径数字。
  • eFPGA / ASIC 只有极头部自营会做。
  • LLM 生成 RTL 的真正风险是：能出 bitstream，但逻辑是错的。

未来 12 个月值得盯

  • Nexus 量产，以及 NovaSparks 并入 Exegy 之后的产品形态。
  • STAC-ML El Popo 会不会出现第二家。
  • AMD 下一代 ULL 卡（Risk.net 采访 Hamid Salehi：客户在问 UL3422 之后是什么）。
  • Altera 独立后会不会补金融专用卡。
  • Inline 推理会不会进入真实 tick-to-trade。
  • 24/5、欧股 CTP、中东交易所扩张，推的是 feed 密度，不一定是更低纳秒。
