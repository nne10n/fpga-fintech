# FPGA 在金融科技的应用与前沿（汇报初稿）

资料截止：2026-08-28  
整理说明：本稿只采用可对上公开一手来源的事实。文中数字按三类口径标注：**【STAC】** 为独立基准测试；**【厂商】** 为厂商规格或宣传，未经第三方审计；**【论文】** 为学术研究。不把厂商数写成已审计结论。

---

## 一、总判断

FPGA 在金融里已经是行情处理、TCP 会话、交易前风控、L1 交换的生产默认件，而不是概念验证。

纳秒竞赛的公开天花板，是网络 I/O 反应，不是带完整策略的端到端交易。目前公开纪录是 **【STAC】** STAC-T0：507 字节帧最低 actionable latency **13.9 ns**（Exegy nxFramework + AMD Alveo UL3524，2024-04）。这项测试量的是「触发字段进入 FPGA」到「TCP 订单离开 FPGA」，10GbE，抖动声称 200 ps。它不是完整策略路径。

机器学习已经进入可采购的微秒级推理产品（GBT / LSTM），但还没有进入上述 13.9 ns 热路径。公开金融推理纪录目前在 FPGA 栈上，多为 1–3 µs 量级；厂商 kit 里有约 250 ns 的 inline GBT，仍属厂商数。

## 二、生产应用场景

### 1. 超低延迟交易 / 网络 I/O

关键路径是 PHY → 协议解析 → 触发模板订单 → TCP 发单，CPU 不在这条路上。

- **【STAC】** Exegy nxFramework + AMD Alveo UL3524：507 字节帧最低 actionable latency **13.9 ns**（STAC-T0，2024-04）。量的是触发字段进 FPGA 到 TCP 订单离 FPGA。
- **【厂商】** Exegy nxAccess 在 CME 上 switch SOP-to-SOP：硬件 tick-to-trade + pattern matcher **389 ns**；无 matcher **624 ns**；软件路径 **1.5 µs**。

### 2. 行情、Feed Handler、订单簿

典型工作：A/B 仲裁、解码、归一化、建簿。

- Exegy nxFeed 是现有行情产品线。
- Exegy Nexus 于 2025-06-25 发布，计划 2025 Q4 初量产。**【厂商】** 软件侧约 **2 µs** 拿到行情、策略反应 **<3 µs**；对接 tick-to-trade 时多市场聚合 **<350 ns**。
- **【厂商】** Celoxica QDS 宣称覆盖 **80+** 场所。

### 3. 下单、DMA、会话

- Celoxica GXA。
- Exegy FPGA FIX 引擎：最多 **128** sessions。**【厂商】** 称主机约 **2 核**，对比软件路径约 **40 核**。

### 4. 交易前风控（15c3-5 / MiFID II）

这一条在生产里很实，不是展会概念。

- Celoxica MAG：**【厂商】** FIX 单位数微秒级线到线，Native 数百纳秒。2026 TradingTech Europe 获 Best Pre-Trade Risk Controls。
- Algo-Logic PTRC：**【厂商】** 10GbE 完整检查远低于 **1 µs**。
- Magmio：**【厂商】** 称低至 **200 ns**（Alveo UL3524 / Cisco Nexus SmartNIC）。

### 5. 网络卸载与 L1

- Exegy：**【厂商】** 全 TCP **53 ns** RTT、UDP **43 ns** RTT。
- LMS ÜberNIC（Intel Agilex + PCIe 5.0 + CXL）：**【STAC】** STAC-N1（2024-05）首次公开测全 FPGA UDP 栈和 CXL 栈，66 字节 mean **1.9 µs**。
- Cisco Nexus SmartNIC。
- Arista 7130 是机房标配，不是加速卡：L1 交换 **5–6 ns**，MetaMux 约 **39 ns**（厂商规格，属交换机产品线）。

### 6. 交易路径上的机器学习

有产品、有 STAC，但量级是微秒，不是纳秒。

- Xelera Silva：**【STAC】** STAC-ML El Popo（2026-05-27）GBT_A p99 **1.60 µs**。**【厂商】** kit 称 UL3524 上 LightGBM p99 约 **250 ns**。
- Myrtle VOLLO：CEO 称「数十万小时生产交易」；**【STAC】** STAC Summit 2026-04 p99 低至 **2 µs**（Versal Premium VP1802）。
- AMD FINN 是工具链，不是交易产品。

### 7. 密码学

HFT 热路径的公开材料几乎不谈 TLS / HSM，不宜写成主流用途。

## 三、技术路径：为什么是 FPGA

**FPGA 本身的理由：** 确定时延、线速并行、可改写。关键路径不走操作系统调度。

**相对 CPU：** CPU 仍跑策略、会话、审计。Feed、发单、风控如果走软件，抖动会上来。

**相对 GPU：** GPU 强在吞吐和训练。HFT 要的是 batch=1、抖动接近零。公开 STAC-ML 金融推理纪录目前在 FPGA 栈（Myrtle / Xelera）。

**相对 ASIC：** 协议和监管会变，FPGA 可重配。eFPGA 嵌进 ASIC 不是主流加速卡形态。

**主流生产形态：** 行情 + TCP + 风控 + 触发模板在 FPGA，复杂 alpha 在 CPU。AMD UL3524 / UL3422 的 GTF 收发器 **<3 ns** 是近端 loopback 的硅片 I/O，不含协议，**不是交易延迟**。

## 五、2024–2026 近期前沿

1. **专用超低延迟硅片。** UL3524 的 GTF + 硬化 MAC/PCS，支撑了 **【STAC】** STAC-T0 13.9 ns。
2. **CXL SmartNIC。** **【STAC】** STAC-N1（2024-05）已测。CXL 3.0 cache-coherent 进入热路径的公开生产案例仍少。
3. **ML 产品化。** STAC-ML 从 LSTM 扩到 El Popo GBT（2026-05）。大模型 / Transformer 没有纳秒级 tick-to-trade 的公开生产证据。
4. **学术侧。** LightTrader（HPCA 2023）；Liu et al.（IEEE ASAP 2024）订单簿 **26–209 ns**【论文】；VLSI-TSA 2026 在 Alveo U50 上风控单笔约 **518–530 ns**【论文】；O’Mahony Electronics 2024 期权定价相对 CPU **270–5400×**【论文】，这是定价 / 风险，不是发单。
5. **LLM 写金融 Verilog。** FinHardBench（arXiv:2608.00909，2026-08）：功能正确率 **19–61%**【论文】。能综合，但算错很常见，不能当生产 RTL 主力。

## 六、风险、未铺开项，以及未来 12 个月

**困难、尚未铺开：**

- 完整策略进 FPGA。
- 纳秒级 ML：公开 inline GBT 约 250 ns 为厂商 kit；LSTM / NN 多在 1–3 µs。
- 深订单簿对延迟：片上内存不够。
- 公开超低延迟多数仍是 10G。
- CXL 没有 T0 量级的热路径数字。
- eFPGA / ASIC 只有极头部自营会做。
- LLM 生成 RTL 的真正风险是：能出 bitstream，但逻辑是错的。

**未来 12 个月值得盯：**

- Nexus 量产，以及 NovaSparks 并入 Exegy 之后的产品形态。
- STAC-ML El Popo 会不会出现第二家。
- AMD 下一代 ULL 卡（Risk.net 采访 Hamid Salehi：客户在问 UL3422 之后是什么）。
- Altera 独立后会不会补金融专用卡。
- Inline 推理会不会进入真实 tick-to-trade。
- 24/5、欧股 CTP、中东交易所扩张，推的是 feed 密度，不一定是更低纳秒。
