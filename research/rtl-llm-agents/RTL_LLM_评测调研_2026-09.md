# LLM/Agent RTL 设计评测调研（截至 2026-09）

> 取证限制：本会话 web_search 可用，但 web_fetch 对 arxiv/semanticscholar/dl.acm/preprints 等域一律被 DNS 策略拒绝，**全文与图表数字均未核实**。以下仅能确认「论文存在 + 标题 + 来源页 + 大致年月」，凡数字均标注来源层级。

## ① 评测口径对比表

| 口径 | 测什么 | 主要局限 | 可信度 |
|---|---|---|---|
| pass@1 / pass@k（testbench） | 给定隐藏 TB 的功能通过率 | TB 由谁写决定上限；覆盖不足；TB 与参考实现同源 | 中（仅当 TB 独立且覆盖可查） |
| 形式等价性（SAT/EC） | 与参考 RTL 的严格等价 | 需黄金参考；对「规范本身错」无效；时序/复位/未知态语义难对齐；规模受限 | 高（但只看等价口径） |
| Agentic（生成→仿真→报错→修复） | 多轮闭环后成功率 | 轮数/预算不统一，成绩不可横向比；工具与 TB 可作弊 | 中低（须报预算） |
| 综合/PPA in-the-loop | 可综合 + 面积/时序/功耗 | 工艺库与约束敏感；PPA 常被当"加分项"而非闸门 | 低–中（口径必须写清） |

- 代表基准：[VerilogEval](https://arxiv-org.ezproxy.obspm.fr/html/2309.07544v2)（2023-09，156 题）、[RTLLM](https://dl.acm.org/doi/abs/10.1109/ASP-DAC58780.2024.10473904)（2024-01，ASP-DAC）、[Revisiting VerilogEval](https://ar5iv.labs.arxiv.org/html/2408.11053)（2024-08）、[RTLLM 2.0]（未核实具体页）。
- 关键二手判断（**媒体/论文摘要层**）：[LLM-Aided Design and Evaluation of a RISC-V Processor](https://ieeexplore.ieee.org/document/11570171)（2026）摘要称 VerilogEval/RTLLM 的高通过率"已无区分度（little headroom）"——即榜单饱和，不能用它推断工程能力。
- 综合/PPA 并入指标：[COEVO](https://www.emergentmind.com/papers/2604.15001)（2026-04，功能正确性 + PPA 联合优化）、[Synthesis-in-the-Loop Evaluation of LLMs for RTL Generation](https://dl.acm.org/doi/full/10.1145/3787109.3815245)（GLSVLSI 2026，质量/可靠性/失败模式）。**均为论文自测，数字未核实。**
- Agentic 与单次生成的量化差距：**未核实**（[Can EDA Tool Feedback Improve Verilog Generation by LLMs?](https://ar5iv.labs.arxiv.org/html/2411.11856)，2024-11；[Automatically Improving LLM-based Verilog Generation](https://dl.acm.org/doi/10.1145/3723876)，TODAES 2025）——方向一致（闭环优于单次），具体百分比未证实。

## ② 失败模式清单（按证据强度）

- **强（多篇同向，论文自测）**：语法/编译错误；位宽不匹配；锁存器误推（incomplete assignment）；复位/初始化缺失；把时序逻辑写成组合逻辑；FSM 状态/转移覆盖不全；协议 valid/ready 握手错误。来源：[How LLMs Fail and Generalize in RTL Coding](https://www.semanticscholar.org/paper/How-LLMs-Fail-and-Generalize-in-RTL-Coding-for-Liu-Yang/747355d3dc71329c232d6fa3820c96c44bc9c826)（2026-06）、[Synthesis-in-the-Loop...](https://dl.acm.org/doi/full/10.1145/3787109.3815245)（2026）、[Verilog 综述 Limitation 4](https://www.preprints.org/manuscript/202511.0656)（2025-11；v2 见 [arXiv 2512.00020](https://arxiv-org.ezproxy.obspm.fr/html/2512.00020v2)，2025-12）。
- **中**：仿真通过但综合失败 / 时序不收敛（Synthesis-in-the-Loop 主题）；跨时钟域处理错误（综述类提及，频率未核实）；长规格与大仓库下的模块级集成失败、接口不匹配、自造 API 幻觉（[VeriGraphi](https://ar5iv.labs.arxiv.org/html/2604.14550)，2026-04，分层多 agent；具体失败率未核实）。
- **弱/未核实**：各错误类型的出现频率占比；验证侧（UVM/SVA/覆盖率）与调试能力的具体差距（[AssertLLM2](https://ar5iv.labs.arxiv.org/html/2605.27472)，2026-05；[PALM](https://ieeexplore.ieee.org/document/11539183)，2026）。

## ③ Benchmark 陷阱与规避

| 陷阱 | 证据 | 规避 |
|---|---|---|
| 训练数据泄漏 | [VeriContaminated](https://ieeexplore.ieee.org/document/11106053)（2025-03；IEEE 版 11106053）；[CircuitGuard](https://ieeexplore.ieee.org/document/11310859)（2026）防 IP 记忆 | 时间切分切片、改写题目、n-gram/成员推断检测、污染版对照 |
| 玩具化题目、无接口约束 | VerilogEval/RTLLM 均为小模块；RISC-V 论文摘要批评榜单饱和 | 补多模块 SoC/真实 IP 集成子集 |
| 评分宽松 / 把编译通过当正确 | [GateTruth 变异测试审计](https://huggingface.co/papers/2608.12635)（2026-08，GateTruth Score = Pass@1 × 归一化变异杀伤率） | 主动变异注入测 TB 杀伤率，报告 TB 弱项 |
| 依赖参考实现 | 综述 Limitation 4（2025-11） | 用规范 + 断言，而非 diff 参考代码 |

## ④ 「可信评测结论」判断准则

1. TB 来源独立、覆盖与随机化可查；公布变异杀伤率或覆盖率，而非只给通过率。
2. 报 agentic 结果必须绑定轮数/仿真次数/工具版本预算，否则不可比。
3. 功能正确性与 PPA 分列，并写明工艺库、约束与综合工具。
4. 有污染对照（去泄漏版本）与 held-out 新题。
5. 覆盖长规格/多模块/接口冻结场景；只看 VerilogEval 分数不作为工程能力证据（榜单已饱和）。
6. 区分来源层级：**论文自测 > 公开榜单（可复现）> 厂商宣传 > 媒体二手**；本文所有数字属前两类的二手转述，使用前须回原文复核。
