## 目标

完成金融科技 × FPGA 产品**通信基建第一步**：只建「能进能出」底座，不扩策略/订单簿等业务 scope。

1. **S1** — TCP 网络帧 payload 提取（64b AXIS 入/出）
2. **S2** — FPGA 产物 UDP 组播出（单包 <512B，TX-only）

---

## 优先级（已裁）

**先 S2，后 S1。**

S2 依赖少，可先冒烟「FPGA 产物能出网」；S1 入侧语义已钉死，但仍比 S2 重。编码验证按此序推进。

---

## 硬约束（摘自边界单，变更才改）

| 编号 | 约束 |
| --- | --- |
| S1 形态 | 选项 A：仅 strip 头 → 纯 TCP payload；不做完整 TCP 栈 / 握手 / 重传 / 乱序重建 |
| S1 入/出 | **H4：** 入侧 = 带 L2–L4 的网络帧/包；出侧 = 纯 TCP payload（64b AXIS，吃 `tkeep`/`tlast`） |
| S2 形态 | A/B TX-only；单包 **<512B** 口上可拦；**永不对组地址 ARP** |
| S2 TTL / RX | **H2：** TTL = 1；**H3：** 本步无 RX / IGMP |
| 组/端口 | **H1：** meta/CSR **参数化**，待机房实参；**禁止写死** |
| 门禁 | 无边界单不开 D1（已满足）；扩 scope 须书面变更 |
