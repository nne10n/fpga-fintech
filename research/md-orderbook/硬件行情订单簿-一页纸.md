# 硬件行情订单簿 — 一页纸（调研过眼定稿）

过眼：2026-09-11。Harness 原稿 `/workspace/fpga-md-orderbook-onepager-out.md`。已删/降级无 URL 硬断言、架构句、未核实 ns。H1–H5 未改。

## 1. 背景
硬件行情订单簿（仓 `melon5253/fpga-md-orderbook`；边界 `docs/boundary/硬件行情订单簿-边界单.md @ e9a2232`）。
口径：≤4096 标的、DDR 全量 L2 档、片上买卖各十档最优投影；不做策略/报单，不做完整会话栈。
本页只服务验收与风险，不给架构。

## 2. 硬约束对齐
- **H1** 簿内核协议无关；feed 适配后置。
- **H2** DDR 存 L2 聚合档（价位 Σqty，可选 order count），非 L3 逐单。
- **H3** 十档 = 各侧 10 个聚合价位；DDR 权威；片上为投影须修补；非十笔订单。
- **H4** 固定 4096 槽；超限拒收且可观测；本步不动态扩表。
- **H5** 本步无缺口恢复；可标脏。

## 3. 惯例
- **L2 全量**：价位→Σqty；可选 order count。全深在片外、Top-N 为窗口，是论文/厂商常见切法（He 2017；Liu 2024；Algo-Logic 厂商宣传默认 L2=10）。
- **片上 Top-N**：避免热路径每次扫全深；Algo-Logic 公开材料写默认 10 档（**厂商宣传**）。
- **几千标的固定槽**：公开容量口径跨 8k–数十万/卡不等（nxAccess 约 8k 建簿路径、NovaSparks 历史约 8191，**均为厂商/旧稿**）。固定 4096 槽落在该区间属业务选择，不是行业唯一口径。
- **协议无关事件（适配层产出，勿写进内核字段）**：symbol、side、price、qty、事件类型（加/改/撤/成交等）；逐单 feed 先反查再改 Σqty，聚合 feed 直接给档变更。**不要把 stock locate / ITCH message type 写进内核**（H1）。
- **标脏 vs 恢复**：序号缺口等由适配/入侧检；重传/快照灌簿不在本步（H5）。NovaTick 等把 late-join/recovery 放 CPU（**厂商旧述**）。

## 4. 注意
- 空档：量为 0 通常「删档」；「留零」会污染 Top-N。具体交易所惯例**未核实**，作开放选项。
- 十档：优于第 10 的插入、撤第 k、量变 0、窗口外变动，均须修补投影，否则与 DDR 权威分叉。
- slot：symbol→slot 唯一；未知/超限拒收可观测；复用前须清簿。
- 脏后：静默 / 打标 / 停更新须与下游约定，禁止把脏簿当干净簿。

## 5. 坑
- L3 当 L2 存（违 H2）。
- 片上与 DDR 口径/时序不一致。
- 超限静默丢（违 H4）。
- 内核写死交易所字段（违 H1）。
- 标脏当成已恢复。
- 未核实 ns、无来源容量当验收。

## 6. 开放选项（非架构决议）
| 主题 | A / B / C | 服务 |
|---|---|---|
| L2 档如何索引（业务语义） | A 每标的价位表／B 稀疏价聚合／C 仅窗口外另计 | H2·H3 |
| 十档对外 | A 按需快照／B 增量／C 定时快照+增量 | H3 |
| 超限可观测 | A 计数/状态／B 告警事件／C 拒绝计数上报 | H4 |
| 适配→内核粒度 | A 单条规范化事件／B 小批量／C 快照+增量（易碰 H5，慎） | H1·H2 |
| 脏后对外 | A 静默／B 打标 dirty／C 停更新 | H5 |
| 空档 | A 删档／B 留零／C 窗口外丢弃并计数 | H2·H3 |
| 投影修补时机 | A 每次变更／B 批尾／C 周期刷新 | H3 |
| slot 复用 | A 禁止／B 清簿后复用／C 按规则回收 | H4 |
