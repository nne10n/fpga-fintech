## D1. 架构分区

### D1.1 双核边界（CONFIRMED）

系统拆成两个独立内核，**不得合并为一个 FSM**：

```text
原始/增量成交或委托记录
          |
          v
  px_level_merge（①） -- 全量价位流 --> l0_top10（②）
          |                               |
          | AXI-M①                        | AXI-M②（仅 <10 补档读）
          +---------------+---------------+
                          v
                     AXI crossbar
                          |
                          v
                    DDR：全量 L2
```

#### ① `px_level_merge`

- 输入是原始/增量成交或委托记录；交易所线编码和具体输入字段本轮保持 TBD。
- 通过本内核独享的 DDR AXI master 读取同价历史，合并成该价位的**完整
  Σqty**，再写回 L2。
- ① 是 L2 的维护者和写入权威。
- 向 ② 单向发送完整价格档位记录，不发送 qty 增量。

#### ② `l0_top10`

- 唯一数据面输入是来自 ① 的完整 qty 价格档位流。
- ② 只维护片上买卖各侧 Top-10 投影，不维护 DDR L2，不执行同价 DDR
  read-modify-write。
- ② 仅在 R3 条件下，经本内核独享的、与 ① 相互独立的 DDR AXI master
  只读补档。

架构总原则为：**① maintains L2；② is projection only（①维护 L2；②仅为投影）**。

### D1.2 ② 的确定行为（CONFIRMED）

| 规则 | 已确认行为 |
| --- | --- |
| Role A | 对 ① 的 `ready` 恒为 1；② 不得反压 ①。非入选档位丢弃 |
| R1 | 同一 `px` 到达时以输入的完整 `qty` 覆盖；`qty == 0` 时从 Top-10 移除 |
| R2 | `(side, px)` 属于当前 best-10 时写入/驱逐；否则丢弃**整张 ticket**，不写 L0，且本内核不做 DDR RMW |
| R3 | 仅当该标的、该侧片上有效档位数 `< 10` 时，旁路发起 DDR 深档只读补档；过期 `rsp.seq` 必须丢弃，不得覆盖 L0 |

本稿不扩展“当前 best-10”的判定算法、排序微结构或周期安排。发生 Role A
丢弃不代表可以反压 ①，也不得把 ticket 的部分字段写入 L0。

### D1.3 AXI 拓扑（CONFIRMED）

- ① 配置一个独立 DDR AXI master，用于同价历史读取与完整 Σqty 写回。
- ② 配置另一个独立 DDR AXI master，仅用于 `<10` 条件下的深档只读补档。
- 两个 master 到 DDR 的汇聚/分发必须使用 **AXI crossbar**。
- crossbar 必须先完成 IP/文档的 catalog 登记，再实例化；用户后续提供具体
  IP 与文档。
- 禁止手写 AXI interconnect，也禁止未经分页/仲裁定义的双 master 直连。

crossbar 型号、端口参数、地址分页及仲裁策略均未在本轮锁定。

## D2. 接口契约

### D2.1 ① → ② 完整价位流（CONFIRMED）

该端口是单向语义通道；② 只消费完整价格档位，不接受原始成交/委托增量。

| 字段 | 方向 | 契约语义 |
| --- | --- | --- |
| `hashid` | ① → ② | **等价于固定槽号 `0..4095`**；接口内不存在 hash→slot CAM |
| `side` | ① → ② | 买卖方向；线编码 TBD |
| `px` | ① → ② | 聚合价格；宽度与编码 TBD |
| `qty` | ① → ② | 该 `(hashid, side, px)` 的**完整 Σqty**，不是增量 |
| `seq` | ① → ② | 补档防陈旧的 generation；宽度、回绕规则 TBD |
| `valid` | ① → ② | 当前 ticket 有效 |
| `ready` | ② → ① | Role A 下恒为 1，② 不得施加反压 |

握手不锁定额外延迟或吞吐指标。`hashid` 已是槽号；上游如何把 symbol 解析为
槽号不属于本接口中的 CAM 职责。

### D2.2 ① 的 DDR 契约摘要（CONFIRMED）

1. 按同价位读取 L2 历史。
2. 将输入增量与历史合并为完整 Σqty。
3. 把完整结果写回 L2。
4. 向 ② 输出该完整结果。

以上是职责及数据语义，不锁定 AXI 数据宽度、burst、outstanding、地址映射、
读写周期或完成顺序细节。

### D2.3 ② 的补档契约摘要（CONFIRMED）

- 触发条件只能是对应 `hashid/side` 的片上有效档位数 `< 10`。
- 补档路径对 DDR 只读，不得升级成 L2 写回或同价 RMW。
- 返回的 `rsp.seq` 过期时，整条响应丢弃，且不得覆盖 L0。
- `seq` 是本轮唯一锁定的补档防陈旧手段。

请求/响应具体字段、地址形成、返回条数和并发数量保持 TBD。

### D2.4 复位与异常（CONFIRMED）

- `sys_rst_n` 使相关控制状态回到 IDLE。
- 罕见异常默认处理铁律：**drop + sticky 可观测 + `sys_rst_n` → IDLE**。
- 不得为罕见异常堆叠恢复 FSM。
- 本轮只允许 `seq` 防陈旧、sticky/dirty 标记和系统复位回 IDLE；禁止加入
  self-heal、多次重试或 recovery AXIS。

sticky/dirty 的寄存器地址、位定义及清除方式尚未锁定。

## D3. 验收意图

本节只记录后续验收应证明的契约，不提供 TB、仿真代码或周期级性能门槛。
详细业务范围仍以边界单第 5 节为准。

| 验收主题 | 意图 |
| --- | --- |
| 双核隔离 | 证明 ① 维护 DDR L2、② 仅维护投影，二者不是单一 FSM |
| 完整 qty | 证明 ①→② 的 `qty` 是完整 Σqty；② 同价覆盖而非累加 |
| Role A | 证明 ② `ready` 恒为 1，且非入选 ticket 被整张丢弃、不反压 |
| R1/R2 | 证明 `qty==0` 删除；best-10 写入/驱逐；未入选不写 L0、不在 ② 发起 DDR RMW |
| R3 | 证明仅有效档位数 `<10` 才只读补档；过期 `rsp.seq` 不覆盖 L0 |
| AXI 隔离 | 证明 ① 和 ② 使用独立 master，并通过已登记 crossbar 接入 DDR |
| 异常/复位 | 证明异常走 drop + sticky/dirty，可由 `sys_rst_n` 回到 IDLE，且没有隐式恢复路径 |

上述“证明”是验收意图指针，不代表吞吐率、延迟或覆盖率数字已获批准。

## D4. 风险、假设与未决项

### D4.1 已知开放风险

DDR 深档在 ② 的补档返回时可能已陈旧。本轮**不宣称消除该风险**：仅以
`seq` 拒绝已识别的陈旧响应，并以 sticky/dirty 提供可观测性。不得自行发明
self-heal、多次重试或 recovery AXIS。更完整的恢复机制须留待后续书面变更单。
