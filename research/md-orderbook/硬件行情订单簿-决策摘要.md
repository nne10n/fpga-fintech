## 目标

FPGA 上维护行情订单簿：**最多 4096 标的**；**DDR 全量 L2 聚合档**；**片上买卖各 10 个最优聚合价位**（DDR 权威，片上为投影并修补）。不做策略/报单，不重做完整会话栈。

---

## 硬约束（H1–H5，已裁定）

| ID | 裁定 |
| --- | --- |
| H1 | 簿内核**协议无关**；feed 适配后置 |
| H2 | DDR = **L2 聚合档**（Σqty，可选 order count），非 L3 逐单 |
| H3 | 十档 = 各侧 **10 个聚合价位**；DDR 权威；片上投影须修补；非十笔订单 |
| H4 | **固定 4096 槽**；超限拒收且可观测；本步不动态扩表 |
| H5 | 本步**无缺口恢复**；可标脏 |

---

## 调研要点（摘自一页纸，不落架构）

- **惯例：** 全深 L2 在片外 + Top-N 窗口常见；固定 4096 落在公开「几千～数万/卡」口径区间（厂商旧稿，非唯一标准）；规范化事件由适配层产出。
- **须防：** L3 当 L2；片上/DDR 分叉；超限静默丢；内核写死交易所字段；标脏当已恢复；未核实 ns 当验收。
- **开放选项（未引入新硬约束）：** 见一页纸 §6（空档删/留零、十档对外形态、超限可观测手段、脏后对外、投影修补时机、slot 复用等）。
