# FPGA / Fintech Research

本仓库存放研究报告；每个研究主题位于独立目录，命名为 `<topic-slug>-YYYYMMDD-HHmm`（Asia/Shanghai 时区）。

**默认交付物**为**完整详细研究报告**（多章节、机制覆盖充分、对比表、假设与出处）。仅当任务明确要求「一页纸」/ one-pager 时，才将 `report.md` 限制为一页结构。

**研究强度：** 多源交叉核对；机制性论断须可核查；避免空泛口号；正文标注 **事实 / 推断 / 待核实**。

**证据留存（每个新调研目录必填）：** `sources.md`（可点击 URL + 各源支撑点）、`report.md`（论断绑定来源与证据等级）；`evidence/` 可选但推荐（摘录、抓取备注、对比草稿，不含密钥）。

This repository holds research reports; each topic lives in its own directory named `<topic-slug>-YYYYMMDD-HHmm` (Asia/Shanghai timezone).

**Default deliverable:** a **full detailed research report** (multi-section, thorough mechanism coverage, comparison tables, assumptions, sources). Produce a one-page `report.md` **only** when the task explicitly requests「一页纸」/ one-pager.

**Research intensity:** cross-check multiple sources; mechanism claims must be verifiable; avoid empty slogans; mark claims as **fact / inference / to verify** (事实 / 推断 / 待核实).

**Evidence retention (required for every new topic folder):** `sources.md` (clickable URLs + what each source supports), `report.md` (claims tied to sources with evidence grades); `evidence/` optional but preferred (short excerpts, fetch notes, comparison scraps — no secrets).

See [docs/README.md](docs/README.md) for the directory convention and report template.
