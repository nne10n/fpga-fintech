## 1. 背景

Pegasus 是 D-Wave 为其第三代量子退火处理器 **Advantage**（2020 年发布）设计的量子位连接拓扑，取代第二代 Advantage 系统之前的 Chimera 拓扑。2025 年起的新一代 **Advantage2** 改用更密的 Zephyr 拓扑（度 20），但 Pegasus 仍是当前装机量最大、Ocean 软件栈支持最成熟的退火拓扑。拓扑编码（qubit 索引、耦合器寻址、邻接关系计算）是在 FPGA 上实现退火仿真器、Ising/QUBO 求解加速器、嵌入（minor-embedding）算法加速的底层基础。

权威定义来源：Boothby et al., *Next-Generation Topology of D-Wave Quantum Processors*（arXiv:2003.00133，D-Wave 技术报告 14-1026），以及 Ocean 软件栈 `dwave-networkx` 中 `pegasus_graph()` 的构造代码（`dwave/graphs/topologies/pegasus.py`）。**本文所有公式均以这两处为准，并已用代码复算核实**。

## 2. 拓扑结构归纳

### 2.1 顶点（量子位）坐标

每个量子位是一个四元组 `(u, w, k, z)`：

| 字段 | 含义 | 范围（P_M） |
|---|---|---|
| `u` | 取向：0 = 垂直，1 = 水平 | {0, 1} |
| `w` | 横向条带编号（perpendicular major offset） | 0 … M−1 |
| `k` | 条带内位置（minor offset，一个条带 12 条量子位线） | 0 … 11 |
| `z` | 沿线方向的位置（parallel offset） | 0 … M−2 |

可以把 Pegasus 想象成一张 2×M 的"编织网格"：共有 2M×12 条量子位线，垂直线与水平线在每个交叉点成对耦合；`z` 就是线上的位置。整个图 P_M 共 **24·M·(M−1)** 个顶点；裁掉两端悬挂的残线后得到**主织构（main fabric）** 24·M·(M−1) − 8·(M−1) 个顶点。

**P16（Advantage 实机）= 5640 个可用量子位、40484 个耦合器**（fabric 全量 5760）。

### 2.2 三类耦合边（全部耦合关系的精确定义）

对主织构内任意两点，存在耦合当且仅当满足以下三条之一：

1. **内部耦合（internal，长程斜耦合，每量子位 12 条）**：垂直量子位 `(0, w0, k0, z0)` 与水平量子位 `(1, w1, k1, z1)` 耦合，当且仅当
   - `w1 = z0 + (1 if k1 < S0[k0] else 0)`
   - `z1 = w0 − (1 if k0 < S1[k1] else 0)`

   其中 S0、S1 是两组长度 12 的**移位向量**，取值 ∈ {2, 6, 10}。Advantage 实机（`offsets_index=0`）使用：
   - `S0 = (2,2,2,2,10,10,10,10,6,6,6,6)`
   - `S1 = (6,6,6,6,2,2,2,2,10,10,10,10)`

   直观理解：垂直线与水平线在 `(w, z)` 网格的**相邻对角交叉处**成对相连，移位向量决定交叉点落在格子的哪个角上。这是 Pegasus 相对 Chimera 多出来的"长程"连接来源。

2. **外部耦合（external，每量子位 ≤2 条）**：`(u, w, k, z) ~ (u, w, k, z±1)`——同一条线上的相邻位置。

3. **奇偶耦合（odd，每量子位 1 条）**：`(u, w, 2j, z) ~ (u, w, 2j+1, z)`——同一条线上相邻两条子线之间。Chimera 没有这一类。

因此 **满配度数 15 = 12（内部）+ 2（外部）+ 1（奇偶）**（处于织构边界时外部/内部各有所裁剪，最大仍为 15）。

> ⚠️ 纠错：包括部分论文综述在内的二手资料常把度 15 拆成 "9 内部 + 4 奇偶 + 2 外部"，这是错的。本文用 dwave-networkx 官方生成器构造 P6/P16 并逐点统计，确认内部量子位平均耦合数恰为 12.000/1.867(≈2)/1.000，即 12+2+1。

### 2.3 索引与坐标系（与 Ocean 工具链互通）

- **线性索引**（Advantage 官方 qubit 编号）：

  `linear(u,w,k,z) = ((u·M + w)·12 + k)·(M−1) + z`

- **nice 坐标** `(t, y, x, u, k)`：`t ∈ {0,1,2}`，`x,y ∈ 0…M−2`，`u∈{0,1}`，`k∈0…3`。每个固定 t 的子图同构于 **chimera(M−1, M−1, 4) + 奇偶耦合**。这个视角对 FPGA 很有价值：Pegasus = 3 层错位堆叠的 Chimera 层加层间短接，Chimera 上的成熟算法/电路可以分层复用。

### 2.4 拓扑特性总结（与 Chimera 对比）

| 特性 | Chimera C16 | Pegasus P16 |
|---|---|---|
| 量子位数 | 2048 | 5640（主织构） |
| 耦合器数 | 6016 | 40484 |
| 单量子位度数 | 6（4 内部 + 2 外部） | **15**（12 + 2 + 1） |
| 原生子图 | K₄,₄ | **K₄ 与 K₆,₆** |
| 树宽 | 4M = 64 | 12M−11 ~ 12M−4（≈180） |
| 原生团嵌入（clique embedding） | 最大 64 变量 | **最大 ~180 变量**（链长 M 或 M+1） |
| 原生二部团 | K₆₄,₆₄（需长链） | K_{12M−20,12M−20}，链长均匀 M−1 |
| 三维立方格嵌入链长 | 长 | 均匀链长 2 |

结构性特点归纳：

1. **高连通、低嵌入围」**：同样的优化问题在 Pegasus 上的嵌入链长比 Chimera 缩短约 50–60%，链越短退火效果越好；
2. **局部性保持**：长程耦合只跨"对角一格"，仍是二维局部结构——物理布线如此，对 FPGA 意味着路由也可以 tile 化、局部化；
3. **规则参数化**：整张图由坐标公式 + 两个 12 项移位向量完全决定，**不需要存任何边表**；
4. **Chimera 兼容**：C_M 是 P_M 的图子式（graph minor），nice 坐标下 3 层 Chimera 结构便于迁移旧设计。

## 3. FPGA 编码方案

目标场景：在 FPGA 上实现 Pegasus 拓扑的退火/模拟量子退火仿真加速器（或嵌入算法加速器），需要高吞吐地完成三类操作：①量子位寻址与索引转换；②给定量子位列出其全部耦合邻居；③判定两点间是否存在耦合、并按耦合器地址读写 h/J 系数与自旋。

### 3.1 地址编码（两层编码，各司其职）

**主编码：打包字段地址（13 bit，运算用）**

```
addr[12]   = u        取向
addr[11:8] = w (0..15)
addr[7:4]  = k (0..11)
addr[3:0]  = z (0..14)
```

**辅编码：线性索引（13 bit，存储寻址/接口用）**，与 D-Wave 官方 qubit 编号一致，便于与上位机软件（Ocean/dwave-networkx）直接交换问题实例：

```
linear = ((u·16 + w)·12 + k)·15 + z
```

两者转换均为纯组合：
- 正向：`·12 = (x<<3)+(x<<2)`，`·15 = (x<<4)−x`，两次乘法各约 2 级 LUT；
- 反向：按基数 15 → 12 → 16 逐级取余（常模除法综合成乘加，约 3–4 级 LUT）。

P16 全图地址空间 13 bit / 5640 项，**h、spin、J 全部实例可驻留片上**：spin 1b×5640 ≈ 0.7 KB；h 若 8 bit 有符号 ≈ 5.5 KB；J 8 bit × 40484 ≈ 40 KB（单向存储）。

### 3.2 邻居生成器（核心：规则生成代替边表查表）

常规做法是把 40484 条边做成邻接表 BRAM（约 132 KB×2 且需预生成）。Pegasus 的规则性允许**零存储、纯组合**地由当前地址算出 15 个邻居。槽位固定约定：

| 槽位 | 类型 | 目标地址 | 有效条件 |
|---|---|---|---|
| 0–11 | 内部 | `{~u, w', j, z'}`，j=0..11：u=0 时 `w'=z+(j<S0[k])`，`z'=w−(k<S1[j])`；u=1 时反解 `z'=w−(k<S0[j])`，`w'=z+(j<S1[k])` | `z'≤14` 且织构边界（w'=0 需 j≥2；w'=15 需 j<10） |
| 12/13 | 外部 | z−1 / z+1 | z 在界内 |
| 14 | 奇偶 | k 翻转最低位 | 织构边界检查 |

电路实现要点：
- 移位向量只需 **12 项 × 4 bit 常量 LUT**（S0/S1 各一张，实际只用 `i[3:2]` 两位做 case）；
- 每个内部槽位 = 1 个 4 bit 加/减法器（z±1 或 w−1）+ 1 个 2:1 mux + 1 个 4 bit 比较器；12 个槽位完全同构，天然并行展开；
- 外部/奇偶槽位几乎是纯连线；
- **总开销约 1–2k LUT6、0 BRAM、0 DSP，1–2 级逻辑深度可收敛到 400 MHz+**（必要时在输出端加一级寄存器成流水）；
- iverilog 全量验证：5640 个量子位 × 15 槽位与 golden model 完全一致。

与查表法对比：邻接表需要 40484×2×13b ≈ 130 KB BRAM + 预处理，且随机访问模式不利于流水；规则生成无存储、可流水、可参数化（改 S0/S1 即适配不同掩模版本/不同 M）。

### 3.3 耦合判定器

给定两个 13 bit 地址，1–2 级 LUT 直接输出是否存在耦合（三选一匹配 §2.2 方程）。用于：J 写入时合法性检查、嵌入算法的图查询、验证通路。已对全部 40484 条边（双向）+ 10 万随机对 + 自身对完成仿真验证。注意它不检查织构有效性——输入应保证是主织构地址（上电时用 3.2 的有效位做一次过滤即可）。

### 3.4 系数/自旋存储编码

| 数据 | 布局 | 寻址 | 资源 |
|---|---|---|---|
| spin（自旋 ±1） | 1b×5640 | linear 直接索引 | 1 个 RAMB36 级别（或寄存器堆全并行） |
| h（局部场） | 8b（1 符号 + 7 幅值，可配）×5640 | linear 直接索引 | ≈2 个 RAMB36 |
| J（耦合强度） | **每量子位连续 15 槽、填充到 16**：`addr_J = linear × 16 + slot`，slot=0..14 与 3.2 槽位一一对应 | linear + 槽号 | 5640×16×8b ≈ 88 KB ≈ 6–8 个 RAMB36/副本 |

J 的"15 槽 pad 到 16"是关键设计决策：slot 号由邻居生成器**同时免费产出**（生成邻居地址的同一拍给出槽位），使 J 读地址 = `{linear[12:0], slot[3:0]}`，纯位拼接、无查找。

读端口策略（按吞吐需求三选一）：
1. **串行扫描**（最小面积）：每量子位 15 拍顺序读 J + 1 拍 h，单口 BRAM，5640 量子位一轮 ≈ 15×5640 拍；
2. **k 路 bank 并行**：按 w 或 z 切 bank，均衡后 4–8 倍吞吐；
3. **全并行**（1 拍/量子位更新）：J 复制 15 份 BRAM（≈0.5 MB）或用 URAM，配合 15 路邻居生成器复制。

### 3.5 微架构组织：沿"线"切分

Pegasus 的天然 FPGA 划分单位是**量子位线** `(u, w, k)`：共 2×16×12 = 384 条线，每条线 15 个量子位（z 方向）。

- 外部耦合 = 线内相邻 → **线内 systolic 流水**（近邻传递寄存器）；
- 内部耦合永远连接 `(w, z)` 网格上的对角相邻线 → 按 16×16 交叉瓦片组织，每瓦片一个 **12×12 稀疏 crossbar**（每线实际只引出 12 根内部耦合线）；
- 奇偶耦合是瓦片内局部连线；
- 若需复用 Chimera 侧已有设计：用 nice 坐标分 3 层，每层即 chimera(15,15,4)+odd，层间用奇偶/外部边短接。

推荐的更新流水线（模拟退火核）：
`取 spin → 生成 15 邻居地址(0 拍,组合) → 并行读 15 个 J + h → ΔE 求和树(15 输入加法树,2 级) → Metropolis/退火判决 → 写回 spin`。全并行方案下单量子位更新 3–4 拍，5640 量子位一 sweep ≈ 2 万拍，500 MHz 下每秒 >2 万次全图 sweep。

### 3.6 参数化与可扩展性

把 `M`、S0、S1 做成参数/寄存器：同一套 RTL 覆盖 P2（调试）~P16（满配），并可在运行时写入**降额图**（Advantage 实机良率裁剪后的 working graph，通常保留 >97% 量子位）——只需按实测良率 mask 掉无效量子位与耦合器（每量子位 1 个 15 bit mask 寄存器即可）。框架向 Zephyr（度 20）扩展时，邻居方程与槽位约定需按其结构重推，但"坐标编码 + 规则生成 + pad-16 存储"的方法论不变。

### 3.7 验证与交付路径

- **golden model**：`ref/pegasus_ref.py`，纯 Python 无依赖，复现官方计数（P6=680/4484，P16=5640/40484，max degree 15）；
- **RTL 验证**：`tb/gen_vectors.py` 自动生成向量并驱动 iverilog——邻居 84600 项、耦合判定 181368 项全部通过（含所有边双向、随机非边、自耦合负样本）；
- **lint**：verilator --lint-only 干净（仅风格类提示）；
- 本机无 Vivado：交付物为纯 RTL + 自包含验证环境，目标环境上只需 `iverilog`/`verilator` 或任意综合器即可复跑；综合约束仅需将 `pegasus_neighbors` 输出寄存一拍，无特殊 XDC 要求。
